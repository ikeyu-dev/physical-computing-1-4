# こもり

手の動きで、画面の中の小さな生き物と触れ合う作品。

Webカメラで手の動きを読み取り、キャラクター「こもり」が反応します。ゆっくり手を動かすと目で追い、急に動かすと驚いて殻に隠れるなど、接し方によって反応が変わる体験を目指します。PCとWebカメラを使い、1人で遊ぶ想定です。

現在は企画・デザイン段階です。実装はまだ開始していません。

## 開発の目的

手の動きに応じた反応を通して、画面の中のキャラクターに生き物らしさや愛着を感じられる体験を作ります。動く速さや反応するまでの間を調整し、相手の様子を見ながら接し方を変えたくなる表現を探ります。

## 最初に実装する内容（予定）

- カメラに映った手の位置を、画面上の小さな印で示す。
- こもりが手の位置に合わせて目や顔を動かす。
- 手を急に動かすと殻に隠れ、静かに待つと少しずつ顔を出す。
- まばたきや呼吸の動き、効果音を加える。

最初は画面上の手の位置と動く速さを使って判定します。触れ合いの履歴に応じて反応を変える仕組みも検討します。
