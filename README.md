# こもり

手の動きで、画面の中の小さな生き物と触れ合う作品。

PCのWebカメラに手を映し、こもりにそっと近づきます。こもりは喋らず、目線や表情、殻に隠れる動きで気持ちを伝えます。既存Figmaの線画を使った、操作感を調整するためのプロトタイプです。

## 起動

Node.js 22.14以降と、WebカメラのあるPCを使います。Chromeで動作確認しています。

```sh
npm ci
npm run dev
```

表示されたローカルURL（通常 http://127.0.0.1:5173 ）を開き、「カメラを使って、会ってみる」を選んでカメラを許可してください。カメラなしでも「マウスでためす」で遊べます。準備画面だけにボタンを置き、触れ合い中はこもりと手、短い案内を表示します。

- 手を見せて静かに待つと、こもりが顔を出します。
- 頭のあたりをゆっくり撫でると安心し、急に手を動かすと驚いて隠れます。
- 画面内の手は実際のグーパーを反映します。どちらの形でも同じように撫でられます。
- 十分に安心すると、しばらくして殻に戻り、寝息を立てます。手が長く見えなくなった場合も眠ります。
- 睡眠中に手を一度引き、再び見せると初対面から再開します。眠ってすぐの4秒間は休ませます。
- `Esc` で準備画面へ戻ります。音の有無は準備画面で選べます。

マウスの場合は移動で手を動かし、押している間はグーになります。画面の外へ移動すると手を離した扱いです。矢印キーで移動、スペースでグーパーの切り替えもできます。

カメラ映像はブラウザ内で処理し、保存・送信しません。認識モデル・WASM・フォントもローカル配信します。カメラにはlocalhostまたはHTTPSが必要です。準備画面へ戻るとカメラを停止します。アカウントやバックエンド、リロードをまたぐ状態保存はありません。

## 試作用の設定

数値は遊びながら調整するための仮値です。好感度にあたる「安心度」は内部で0〜100として持ち、ゲージは表示しません。

| 条件                                    | 現在の動き                            |
| --------------------------------------- | ------------------------------------- |
| 待機中                                  | 約8秒ごとに少し顔を出して外をうかがう |
| 急な動きで驚いた後                      | 手を静かにして約2.5秒で顔を出し始める |
| 手が見えない状態が10秒                  | 安心度が下がり、殻に戻り始める        |
| 手が見えない状態が30秒                  | 眠る                                  |
| 安心度が初めてMAXになって20秒           | あくびを経て眠る                      |
| 眠ってから手が1.2秒以上消え、再び現れる | 最低4秒の睡眠後、新しい体験へ         |

手が静止していることは不在とみなしません。手を出したままの睡眠では自動再開しません。眠る前に別の人へ交代した場合は、同じ体験を引き継ぎます。人の識別は行いません。

## 構成と検証

React / TypeScript / Vite、MediaPipe Hand Landmarker、SVG、Web Audioを使用しています。

- `src/input/`：手の認識、位置の平滑化、グーパー判定
- `src/game/engine.ts`：安心度・待機・驚き・睡眠の状態遷移
- `src/game/config.ts`：時間と判定範囲の調整
- `src/components/Komori.tsx`：既存の線画を使った描画

```sh
npm test            # 状態遷移と手の入力処理
npm run build       # 型検査と配布用ビルド
npm run preview     # ビルドした画面の確認
```

開発サーバーを起動した状態で、ローカルにインストールされたGoogle Chromeを使ってブラウザテストを実行できます。

```sh
npm run test:browser
```

ブラウザテストは独立したChromeと模擬カメラを使います。操作・睡眠と再開・実モデルの初期化・カメラ停止・許可拒否時の復帰を確認し、画面を `test-results/` に保存します。人の手での認識精度、展示場所での動かしやすさ、寝息の聴こえ方は実機で調整が必要です。

`npm ci` 時にWASMを `public/vision/` へコピーします。再生成は `npm run prepare:vision`。出典とライセンスは [THIRD_PARTY.md](THIRD_PARTY.md) を参照してください。
